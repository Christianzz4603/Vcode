<b>Vcode</b> is a fast, free and open source code editor and file manager for Android. It is a modified version of Squircle CE and is released under the Apache License 2.0.

<b>Editor</b>
• Syntax highlighting for 49 programming languages
• IntelliSense for JavaScript, TypeScript, Kotlin, Java, Python, HTML, XML and shell, plus keyword suggestions
• Tabs with language icons, auto save, and undo and redo that survive a restart
• Symbol row and a tools bar you can reorder and hide

<b>Run and output</b>
• Bottom panel with Problems, Output, Preview and AI tabs; resize it or open it full screen
• Run JavaScript and shell scripts inside the app
• Run in Termux: runs the open file in the Termux app (Python, Node.js, Java, Kotlin, C, C++, Go, Rust, PHP, Ruby, Perl, R, Dart and shell). Termux is a separate app that you install yourself.

<b>Themes and plugins</b>
• 15 themes, including Vcode Dark, Dark+, Light+, One Dark, GitHub Dark and Dracula
• Data-only plugins that add themes, keyword lists and file types (no code runs from a plugin)

<b>Files and Git</b>
• File manager with SFTP and FTP(S) support
• Git integration: commit, push, pull and branches

<b>Optional AI assistant</b>
• Ask questions about the open file from the AI tab. It uses the OpenRouter service with your own API key.

<b>Free software</b>
• No ads, no Google Play services and no closed-source libraries
• Source code: https://github.com/Christianzz4603/Vcode
